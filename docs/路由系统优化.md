# 路由系统优化

> 微前端路由增强器使用指南

## 📖 概述

路由增强器为微前端应用提供智能的路由管理功能，支持动态路由加载、权限控制、预加载策略等企业级特性。

## 🏗️ 架构设计

### 核心组件

```typescript
MicroRouterEnhancer          // 路由增强器
├── MicroRouteConfig        // 微前端路由配置
├── RouteMatchResult        // 路由匹配结果
└── RouterGuards           // 路由守卫系统
```

## 🚀 快速开始

### 1. 基础配置

路由增强器已在 `src/router/index.ts` 中自动初始化：

```typescript
import { createRouter, createWebHashHistory } from 'vue-router'
import { createMicroRouterEnhancer } from './micro-router-enhancer'

const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    // 基础路由...
  ]
})

// 创建路由增强器
const routerEnhancer = createMicroRouterEnhancer(router)

// 导出以供使用
export { routerEnhancer }
export default router
```

### 2. 注册微前端路由

```typescript
import { routerEnhancer } from '@/router'

// 注册单个微前端路由
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',           // 应用ID
  prefix: '/device',                 // 路由前缀
  preload: true,                     // 是否预加载
  preloadStrategy: 'idle',           // 预加载策略
  permissions: ['device:read'],      // 权限要求
  enabled: true,                     // 是否启用
  guards: {
    beforeEnter: async (to, from) => {
      // 自定义路由守卫
      console.log('进入设备管理模块')
      return true
    },
    afterEnter: (to, from) => {
      // 路由进入后处理
      console.log('已进入设备管理模块')
    }
  }
})

// 批量注册
routerEnhancer.registerMicroRoutes([
  {
    appId: 'device-manager',
    prefix: '/device',
    preload: true,
    permissions: ['device:read']
  },
  {
    appId: 'notify-manager', 
    prefix: '/notify',
    preload: false,
    permissions: ['notify:read']
  }
])
```

## 🛠️ 配置选项

### MicroRouteConfig 配置项

```typescript
interface MicroRouteConfig {
  /** 应用ID - 必填 */
  appId: string
  
  /** 路由前缀 - 必填，如 '/device' */
  prefix: string
  
  /** 是否预加载 - 默认 false */
  preload?: boolean
  
  /** 预加载策略 - 默认 'idle' */
  preloadStrategy?: PreloadStrategy
  
  /** 路由守卫 */
  guards?: {
    /** 进入前守卫 */
    beforeEnter?: (to: RouteLocationNormalized, from: RouteLocationNormalized) => boolean | Promise<boolean>
    /** 进入后守卫 */ 
    afterEnter?: (to: RouteLocationNormalized, from: RouteLocationNormalized) => void
  }
  
  /** 权限控制 - 用户需要的权限列表 */
  permissions?: string[]
  
  /** 是否启用 - 默认 true */
  enabled?: boolean
}
```

### 预加载策略

```typescript
import { PreloadStrategy } from '@/utils/federation-preloader'

const strategies = {
  IMMEDIATE: 'immediate',    // 立即加载
  IDLE: 'idle',             // 空闲时加载  
  VISIBLE: 'visible',       // 可见时加载
  INTERACTION: 'interaction', // 交互时加载
  ROUTE: 'route'            // 路由匹配时加载
}
```

## 🎯 路由匹配和加载

### 1. 自动路由匹配

路由增强器会自动匹配URL并加载对应的微前端路由：

```typescript
// 用户访问 /device/list 时
// 1. 匹配到 device-manager 应用 (prefix: '/device')
// 2. 检查权限: ['device:read']
// 3. 动态加载应用路由
// 4. 重新导航到正确路由
```

### 2. 手动路由加载

```typescript
import { routerEnhancer } from '@/router'

// 预加载应用路由
await routerEnhancer.loadMicroRoutes('device-manager')

// 添加路由到Vue Router
await routerEnhancer.addMicroRoutesToRouter('device-manager')

// 移除应用路由
routerEnhancer.removeMicroRoutes('device-manager')
```

### 3. 路由缓存管理

```typescript
// 清除指定应用的路由缓存
routerEnhancer.clearCache('device-manager')

// 清除所有路由缓存
routerEnhancer.clearCache()

// 预热路由 - 提前加载多个应用的路由
await routerEnhancer.preloadRoutes(['device-manager', 'notify-manager'])
```

## 🔐 权限控制

### 1. 基础权限控制

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device',
  permissions: ['device:read', 'device:manage'] // 需要这些权限
})
```

### 2. 动态权限检查

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device',
  guards: {
    beforeEnter: async (to, from) => {
      // 自定义权限检查逻辑
      const userStore = useUserStore()
      const user = userStore.userInfo
      
      // 检查用户角色
      if (user.role === 'admin') return true
      
      // 检查具体权限
      if (to.path.includes('/admin') && !user.permissions.includes('device:admin')) {
        return false
      }
      
      return true
    }
  }
})
```

### 3. 权限不足处理

当用户权限不足时，系统会：
1. 阻止路由跳转
2. 跳转到 `NotFound` 页面
3. 在控制台输出警告信息

## 🎮 路由守卫

### 1. 前置守卫

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device',
  guards: {
    beforeEnter: async (to, from) => {
      // 数据预加载
      const deviceStore = useDeviceStore()
      if (!deviceStore.initialized) {
        await deviceStore.init()
      }
      
      // 条件检查
      if (to.params.id && !await deviceStore.exists(to.params.id)) {
        return false // 阻止进入
      }
      
      return true // 允许进入
    }
  }
})
```

### 2. 后置守卫

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager', 
  prefix: '/device',
  guards: {
    afterEnter: (to, from) => {
      // 页面统计
      analytics.track('page_view', {
        page: to.path,
        from: from.path,
        app: 'device-manager'
      })
      
      // 面包屑更新
      const breadcrumbStore = useBreadcrumbStore()
      breadcrumbStore.update(to.matched)
      
      // 标题更新
      document.title = `${to.meta.title} - JetLinks`
    }
  }
})
```

## 🔄 事件系统

路由增强器会发布以下事件：

### 1. 监听路由事件

```typescript
import { federationBridge } from '@/utils/micro-federation-bridge'

// 监听路由变化
federationBridge.on('route:changed', (event) => {
  const { to, from, appId } = event.payload
  console.log(`路由变化: ${from} -> ${to} (应用: ${appId})`)
})

// 监听路由加载完成
federationBridge.on('micro-route:loaded', (event) => {
  const { appId, routeCount } = event.payload
  console.log(`${appId} 路由加载完成，共 ${routeCount} 个路由`)
})

// 监听路由加载失败
federationBridge.on('micro-route:load-failed', (event) => {
  const { appId, error } = event.payload
  console.error(`${appId} 路由加载失败:`, error)
})
```

### 2. 发布自定义事件

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device', 
  guards: {
    beforeEnter: (to, from) => {
      // 发布自定义事件
      federationBridge.emit('device-module:entering', 'router-enhancer', {
        route: to.path,
        params: to.params
      })
      return true
    }
  }
})
```

## 🔧 高级功能

### 1. 动态路由生成

```typescript
// 远程应用的路由配置
// src/modules/device-manager-ui/routes.ts
export const routes = [
  {
    path: '/list',
    name: 'DeviceList',
    component: () => import('./views/DeviceList.vue'),
    meta: { title: '设备列表', permissions: ['device:read'] }
  },
  {
    path: '/detail/:id',
    name: 'DeviceDetail', 
    component: () => import('./views/DeviceDetail.vue'),
    meta: { title: '设备详情', permissions: ['device:read'] }
  },
  {
    path: '/admin',
    name: 'DeviceAdmin',
    component: () => import('./views/DeviceAdmin.vue'),
    meta: { title: '设备管理', permissions: ['device:admin'] }
  }
]

// 注册到模块注册中心
export const register = () => {
  const { moduleRegistry } = import('@/utils/module-registry')
  moduleRegistry.register('device-manager', {
    routes: routes
  })
}
```

### 2. 路由前缀处理

路由增强器会自动处理路由前缀：

```typescript
// 原始路由: /list
// 处理后路由: /device/list (prefix: '/device')

// 原始路由: /detail/:id  
// 处理后路由: /device/detail/:id

// 子路由也会自动处理
// 原始: { path: '/list', children: [{ path: 'item/:id' }] }
// 处理后: { path: '/device/list', children: [{ path: '/device/list/item/:id' }] }
```

### 3. 路由元信息扩展

```typescript
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device',
  guards: {
    beforeEnter: (to, from) => {
      // 扩展路由元信息
      to.meta.appId = 'device-manager'
      to.meta.loadTime = Date.now()
      to.meta.breadcrumb = [
        { name: '首页', path: '/' },
        { name: '设备管理', path: '/device' },
        { name: to.meta.title, path: to.path }
      ]
      return true
    }
  }
})
```
