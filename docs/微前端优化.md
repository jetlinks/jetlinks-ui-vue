# 场景
## 项目a 是基座

1. 项目目录
project-a/
   ├── views
   └── modules
        └── authentication-manager-ui
2. 打包 pnpm build

## 项目b 是微前端

1. 项目目录
project-b/
   ├── views
   └── modules
        └── device-manager-ui
2. 打包 pnpm build:modules device-manager

## 项目c 是微前端

1. 项目目录
project-b/
   ├── views
   └── modules
        └── notify-manager-ui
2. 打包 pnpm build:modules notify-manager

# 模块联邦

模块联邦使用@jetlinks-web/vite中的federation，使用方法在docs/动态加载远程组件.md

# 要求
1. 使用模块联邦处理微前端资源共享
2. 优化作为微前端是，router的使用方式
3. 因为使用微前端方式加载应用，module-registry.ts需要做兼容
4. 所有子模块都是通过registry.ts来注册组件和api
5. 基座通过store/application.ts来管理所有微前端的path
6. 模块联邦remotes 都是动态值，不能写死
