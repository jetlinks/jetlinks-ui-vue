# 微前端优化方案

> 基于 Vue 3.5.x + Vite 7.x + Module Federation 的企业级微前端解决方案

## 🎯 方案概述

本方案基于模块联邦（Module Federation）技术，为 JetLinks 平台提供了一套完整的微前端优化解决方案。支持动态加载、智能预加载、性能监控等企业级特性。

### 核心特性

- 🔄 **动态 Remote 配置** - 无需硬编码，运行时动态加载微前端应用
- 🚀 **智能预加载** - 多种预加载策略，提升用户体验
- 📊 **性能监控** - 实时监控加载性能，提供详细统计
- 🎛️ **统一管理** - 完整的应用生命周期管理
- 🔗 **无缝通信** - 跨应用数据共享和事件通信
- 🛡️ **错误处理** - 完善的容错机制和降级策略

## 🚀 快速开始

### 1. 基础配置

在主应用的 `main.ts` 中初始化：

```typescript
import { createApp } from 'vue'
import { installFederationBridge } from '@/utils/micro-federation-bridge'
import App from './App.vue'
import router from './router'

const app = createApp(App)

// 安装微前端桥接器
installFederationBridge(app)

app.use(router)
app.mount('#app')
```

### 2. 应用注册

系统会自动从 API 获取应用列表并注册，也可以手动注册：

```typescript
import { useApplication } from '@/store'

const applicationStore = useApplication()

// 查询并初始化应用
await applicationStore.queryApplication()

// 预加载指定应用
await applicationStore.preloadApp('device-manager')
```

### 3. 组件使用

在 Vue 组件中使用远程组件：

```vue
<template>
  <div>
    <component :is="RemoteButton" v-if="RemoteButton" />
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { loadComponent } from '@/utils/federation-loader'

const RemoteButton = ref(null)

onMounted(async () => {
  const result = await loadComponent({
    remoteName: 'device-manager',
    exposedModule: './Button'
  })
  
  if (result.success) {
    RemoteButton.value = result.data
  }
})
</script>
```

## 📋 核心模块

### 1. Federation Strategy (联邦策略)

管理模块联邦的配置和策略：

```typescript
import { federationStrategy } from '../../federation-strategy'

// 注册远程应用
federationStrategy.registerRemote({
  name: 'device-manager',
  entry: 'http://localhost:3001/remoteEntry.js',
  format: 'esm',
  from: 'vite'
})
```

### 2. Micro Frontend Config (微前端配置)

统一的微前端应用配置管理：

```typescript
import { microFrontendConfig } from '../../micro-frontend-config'

// 初始化配置
await microFrontendConfig.initialize(applications)

// 检查应用状态
const isReady = microFrontendConfig.isAppReady('device-manager')
```

### 3. Router Enhancer (路由增强)

智能的微前端路由管理：

```typescript
import { routerEnhancer } from '@/router'

// 注册微前端路由
routerEnhancer.registerMicroRoute({
  appId: 'device-manager',
  prefix: '/device',
  preload: true,
  permissions: ['device:read']
})
```

### 4. Performance Monitor (性能监控)

实时的性能监控和统计：

```typescript
import { performanceMonitor } from '@/utils/federation-performance-monitor'

// 获取性能统计
const stats = performanceMonitor.getStats()
console.log(`平均加载时间: ${stats.averageLoadTime}ms`)

// 生成报告
const report = performanceMonitor.generateReport()
```

## 🎛️ 应用管理

### 应用状态

应用在整个生命周期中有以下状态：

- `idle` - 空闲状态
- `loading` - 加载中  
- `loaded` - 已加载
- `mounted` - 已挂载
- `error` - 错误状态

### 应用操作

```typescript
import { useApplication } from '@/store'

const app = useApplication()

// 预加载应用
await app.preloadApp('device-manager')

// 批量预加载
await app.batchPreloadApps(['device-manager', 'notify-manager'])

// 重新加载应用
await app.reloadApp('device-manager')

// 启用/禁用应用
app.setAppEnabled('device-manager', false)

// 获取性能信息
const performance = app.getAppPerformance('device-manager')
```

## 📊 性能优化

### 预加载策略

系统支持多种预加载策略：

- **立即预加载** (`IMMEDIATE`) - 应用启动时立即加载
- **空闲预加载** (`IDLE`) - 浏览器空闲时加载
- **可见预加载** (`VISIBLE`) - 组件可见时加载  
- **交互预加载** (`INTERACTION`) - 用户交互时加载
- **路由预加载** (`ROUTE`) - 路由匹配时加载

```typescript
import { preloader, PreloadStrategy } from '@/utils/federation-preloader'

// 添加预加载任务
preloader.addTask('device-manager', {
  strategy: PreloadStrategy.IDLE,
  priority: 8,
  delay: 1000
})
```

### 缓存机制

- **组件缓存** - 已加载的组件会自动缓存
- **路由缓存** - 动态加载的路由配置缓存
- **配置缓存** - 联邦配置缓存

```typescript
import { FederationLoader } from '@/utils/federation-loader'

// 清除指定应用缓存
FederationLoader.clearCache('device-manager')

// 清除所有缓存
FederationLoader.clearCache()
```

## 🔧 故障排除

### 常见问题

**Q: 远程组件加载失败？**
A: 检查网络连接、入口URL是否正确，查看控制台错误信息

**Q: 路由跳转不生效？**  
A: 确认路由配置正确，检查权限设置

**Q: 应用间通信失效？**
A: 验证事件名称和数据格式，检查桥接器是否正确初始化

**Q: 性能较差？**
A: 检查预加载策略，优化网络条件，使用缓存机制
